# 词汇学习方法（How to Learn Vocabulary）

> **来源**：项目原创演示资料
> **用途**：仅用于 RAG 工程演示，不代表真实教学机构或客户资料

## 核心结论

背单词的效果，**不取决于一次花多长时间，而取决于复习了多少次、间隔了多久**。

同样花 10 个小时，分散到 20 天、每天 30 分钟，效果远好于连续背 10 个小时。

## 四个被验证有效的方法

### 1. 间隔重复（Spaced Repetition）

在**快要忘记**的时候复习，记忆最牢固。

一个常见的复习节奏：

| 复习次数 | 间隔 |
| --- | --- |
| 第 1 次 | 学完当天晚上 |
| 第 2 次 | 1 天后 |
| 第 3 次 | 3 天后 |
| 第 4 次 | 7 天后 |
| 第 5 次 | 15 天后 |
| 第 6 次 | 30 天后 |

不需要严格照抄这个表，关键是——**间隔一次比一次长**。

### 2. 主动回忆（Active Recall）

**遮住答案，先自己想**，想不起来再看。

- ❌ 低效：反复读「abandon = 放弃」十遍
- ✅ 高效：看到 `abandon`，先自己回忆意思，再翻答案核对

这个动作有点「费劲」，但正是这种费劲让记忆变牢。反复读十遍感觉很流畅，其实是一种假象。

### 3. 在语境里记，别孤立背单词表

孤立背下来的单词，到用的时候往往想不起来。

- ❌ `available = 可获得的`
- ✅ `Is this seat available?`（这个座位有人吗？）

推荐做法：每个新词记一个**你自己造的句子**，比抄词典例句更有效。

### 4. 词根词缀

掌握常见的前缀后缀，能一次记住一串词。

| 词缀 | 意思 | 例子 |
| --- | --- | --- |
| `un-` | 否定 | unhappy、unfair、unable |
| `re-` | 再一次 | rewrite、replay、reconsider |
| `-able` | 能……的 | readable、washable、affordable |
| `-tion` | 名词后缀 | action、decision、education |
| `-less` | 没有 | hopeless、careless、useless |

注意：词根词缀是**辅助手段**，不是万能规律，会有例外，不要硬套。

## 每天背多少合适

没有一个对所有人都合适的数字，但一般建议：

- **新词**：每天 10～20 个
- **复习**：旧词优先，复习量通常是新词的 2～3 倍
- **频率**：宁可每天少背一点，也不要一周背一次、一次背 200 个

## 常见误区

| 误区 | 问题在哪 |
| --- | --- |
| 只背新词，不复习旧词 | 遗忘速度很快，等于白背 |
| 追求「一次就记住」 | 记忆本来就需要多次重复，这不可能 |
| 按字母表顺序背 | abandon、ability、able…… 相邻的词长得像，反而容易混 |
| 只背中文意思，不看词性 | 不知道是动词还是名词，写句子一定出错 |
| 只输入不输出 | 不造句、不使用，永远停留在「认识但不会用」 |

## 怎么判断自己真的记住了

能通过下面三关，才算真的掌握：

1. **认得**：看到能说出意思
2. **想得起**：想表达某个意思时，能想起对应的单词
3. **用得出**：能造一个语法正确的句子

大多数人停在第一关，就以为记住了。
